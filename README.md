dotfiles
========

Personal terminal setup for **Debian** and **macOS**, split across three layers:

| Layer | Owns | Mechanism |
|-------|------|-----------|
| **[omnishell](https://github.com/JtheGunner/omnishell)** | rc *lines* - plugin inits, history, completion, `fzf`, `zoxide`, `modern-aliases` | one marker block in your rc file, sourcing a generated `init.<shell>` |
| **this repo (stow packages)** | config *files at a path* - `git`, `tmux`, `bat`, `starship`, `mise`, `ghostty` (+ optional `nvim`) | [GNU Stow](https://www.gnu.org/software/stow/) symlinks into `$HOME` |
| **this repo (`shell.d/`)** | personal rc lines not worth a public module - k8s/docker aliases, `linuxbrew`, helper functions, and tools still awaiting an omnishell module (`direnv`, `mise`, `starship`) | a second marker block, sourced *after* omnishell |

omnishell is consumed as a released binary (Homebrew tap / curl installer); this
repo never modifies it.

Install
-------

```sh
git clone https://github.com/JtheGunner/dotfiles ~/.dotfiles
~/.dotfiles/bootstrap.sh
exec $SHELL
```

`bootstrap.sh` installs dependencies + omnishell, stows the packages, applies
`omnishell/config.toml`, wires `shell.d/` into your **current** login shell
(bash or zsh - no `chsh`), and renders the colors. Re-running it is safe.

### Manual / partial

```sh
cd ~/.dotfiles
stow git tmux bat            # only the packages you want
```

Colors: Root Loops
------------------

Terminal colors are defined **once** and everything else inherits the 16 ANSI
colors. See [`rootloops/`](rootloops/):

- [`rootloops/RECIPE`](rootloops/RECIPE) - the canonical [rootloops.sh](https://rootloops.sh) recipe
- [`rootloops/palette.env`](rootloops/palette.env) - the 16 colors + fg/bg (the source of truth)
`rootloops/apply.sh` renders everything that *can't* just inherit the 16 ANSI
colors:

| Target | File | Notes |
|--------|------|-------|
| Any OSC-capable terminal | `shell.d/95-rootloops-term.sh` | Pushes the palette to the **running** terminal via OSC 4/10/11 (tmux-aware). No emulator config needed. GNOME Terminal / VTE (Debian default), kitty, alacritty, wezterm, foot, konsole, xterm, iTerm2, Linux console. |
| GNOME Terminal (persistent) | generated by `rootloops/gen-vte-terminal.sh` | Writes the palette into the **default GNOME Terminal profile** via `gsettings`. Best-effort - silently skipped on non-GNOME. Run automatically by `apply.sh` on Linux. |
| **Ghostty** | `ghostty/.config/ghostty/rootloops` | Native palette, `include`d from `ghostty/.config/ghostty/config`. Ghostty is the primary terminal here (installed by `bootstrap.sh`). |
| macOS Terminal.app *(fallback)* | `rootloops/RootLoops.terminal` | For the OS-default terminal before Ghostty is up. Terminal.app ignores OSC escapes, so it gets an importable profile (`rootloops/gen-terminal-app.py`); `bootstrap.sh` imports it and sets it default. |
| `fzf` UI chrome | `shell.d/70-fzf-colors.sh` | doesn't inherit ANSI cleanly |
| neovim | (later) | once the `nvim` package exists |

`bat`, `tmux`, `git`/`delta` and `starship` inherit ANSI, so they need no
generated file.

**Change the theme:** edit `rootloops/RECIPE` + `rootloops/palette.env`, run
`rootloops/apply.sh` (or `make colors`), commit. On macOS re-import
`RootLoops.terminal`; on GNOME re-run `apply.sh`.

Layout
------

```
bootstrap.sh              one-shot installer
Makefile                  stow / colors / check wrappers
omnishell/config.toml     version-controlled omnishell config
shell.d/*.sh              personal rc fragments (sourced after omnishell)
rootloops/                color single-source (palette.env) + generators
zsh/ bash/ git/ tmux/     stow packages ->  ~/  and  ~/.config/
bat/ starship/ mise/ ghostty/
nvim/                     optional stow package (opt-in)
```

Notes
-----

- `git` config lives at `~/.config/git/config` (not `~/.gitconfig`); the old file
  is backed up to `~/.gitconfig.pre-dotfiles` by `bootstrap.sh`.
- `shell.d/50-less-colors.sh` and the `direnv`/`mise`/`starship` blocks in
  `shell.d/60-tools.sh` are placeholders for planned omnishell modules; when
  those ship, delete the fragment and enable the module in
  `omnishell/config.toml`.
- Adapted in large part from [hamvocke/dotfiles](https://github.com/hamvocke/dotfiles).
