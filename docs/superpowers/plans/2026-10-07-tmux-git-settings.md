# tmux and git Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `~/.config/dotfiles/config.toml` also sets tmux and git values through `[tmux]` and `[git]` tables.

**Architecture:** `lib/settings.sh` learns two tables, thirteen schema rows and four value types, and gains `settings_render_tmux` / `settings_render_git`. `bootstrap.sh` writes the results to generated includes (`~/.config/tmux-settings.conf`, `~/.gitconfig.settings`) that the tracked `tmux/.tmux.conf` and `git/.config/git/config` include; hand-written files are never touched.

**Tech Stack:** Bash 3.2-compatible shell, awk, tmux, git, the repo's `tests/test-*.sh` style.

**Spec:** `docs/superpowers/specs/2026-10-07-tmux-git-settings-design.md`

## Global Constraints

- Precedence unchanged: flag > environment > settings file > default; no new flags or environment variables.
- Every key is optional; an unset key renders nothing, so the tracked default applies.
- Generated files start with `# GENERATED by bootstrap.sh from the settings file - do not edit`, live outside the stowed directories, are removed when no key is set, and a file without that marker is never touched (warning).
- Include order, last wins: tmux = tracked default, `~/.config/tmux-settings.conf`, `~/.tmux.conf.local`; git = tracked default, `~/.gitconfig.delta`, `~/.gitconfig.settings`, `~/.gitconfig.local`.
- Invalid values, unknown keys and render problems are one `warn`, never fatal. The interactive git identity / signing prompts stay as the fallback.
- Bash 3.2 and BWK awk / mawk compatible; the settings file is parsed, never executed.
- Code and docs in English; commit messages `<type>: <description>` without trailers; `make lint test` green before each commit.

## Review Focus

- Setting `prefix = "C-a"` (the tracked default) must still leave a working prefix: `unbind C-a` runs before the rebind. Pinned in Task 2 (real tmux).
- A hand-written `~/.tmux.conf.local` or `~/.gitconfig.settings` without the marker is left untouched. Pinned in Task 3.
- `user_name` with quotes, a backslash or a leading `#` is stored and read back intact (`git config --file`). Pinned in Task 3.
- A `signing_key` that is missing or not a `*.pub` file is skipped with a warning while the other git values are still written. Pinned in Task 3.
- A second run changes nothing, clearing the keys removes the generated files, and a set `user_email` makes the identity prompt skip itself. Pinned in Task 3.

```bash
# plan-apply: append lib/settings.sh

# tmux commands for the [tmux] values that are set, in a fixed order. A prefix
# change unbinds the tracked default C-a first, so setting C-a itself still works.
settings_render_tmux() {
  local v
  v="$(settings_get tmux.prefix)"
  if [ -n "$v" ]; then
    printf 'unbind C-a\nset -g prefix %s\nbind %s send-prefix\n' "$v" "$v"
  fi
  v="$(settings_get tmux.mouse)"
  case "$v" in
    true) printf 'set -g mouse on\n' ;;
    false) printf 'set -g mouse off\n' ;;
  esac
  v="$(settings_get tmux.mode_keys)"
  [ -z "$v" ] || printf 'set-window-option -g mode-keys %s\n' "$v"
  v="$(settings_get tmux.base_index)"
  [ -z "$v" ] || printf 'set -g base-index %s\n' "$v"
  v="$(settings_get tmux.escape_time)"
  [ -z "$v" ] || printf 'set -sg escape-time %s\n' "$v"
  v="$(settings_get tmux.history_limit)"
  [ -z "$v" ] || printf 'set -g history-limit %s\n' "$v"
  v="$(settings_get tmux.status_position)"
  [ -z "$v" ] || printf 'set -g status-position %s\n' "$v"
}

# git-config-key<US>value records for the [git] values that are set. signing_key
# is left to the bootstrap: it needs the public key file to exist and sets four
# keys (see write_git_signing_config).
settings_render_git() {
  local v
  v="$(settings_get git.user_name)"
  [ -z "$v" ] || printf 'user.name%s%s\n' "$SETTINGS_US" "$v"
  v="$(settings_get git.user_email)"
  [ -z "$v" ] || printf 'user.email%s%s\n' "$SETTINGS_US" "$v"
  v="$(settings_get git.default_branch)"
  [ -z "$v" ] || printf 'init.defaultBranch%s%s\n' "$SETTINGS_US" "$v"
  v="$(settings_get git.editor)"
  [ -z "$v" ] || printf 'core.editor%s%s\n' "$SETTINGS_US" "$v"
  v="$(settings_get git.pull_rebase)"
  [ -z "$v" ] || printf 'pull.rebase%s%s\n' "$SETTINGS_US" "$v"
}
```

```python
# --------------------------------------------------------------------------
# 3a''. tmux and git values from the [tmux] / [git] tables of the settings file,
#       written to generated includes outside the stowed directories; the tracked
#       tmux.conf and git config include them. A file this script did not generate
#       is never touched, and with no key set a generated file is removed.
# --------------------------------------------------------------------------
GENERATED_MARK="# GENERATED by bootstrap.sh from the settings file - do not edit"

# true when $1 does not exist or was generated by this script
_generated_or_absent() { [ ! -e "$1" ] || head -n 1 "$1" | grep -qxF "$GENERATED_MARK"; }

render_tmux_settings() {
  local out="$HOME/.config/tmux-settings.conf" body
  body="$(settings_render_tmux)"
  if ! _generated_or_absent "$out"; then
    warn "$out is not generated by bootstrap.sh - left untouched"
    return 0
  fi
  if [ -z "$body" ]; then
    rm -f "$out"
    return 0
  fi
  mkdir -p "$(dirname "$out")"
  printf '%s\\n%s\\n' "$GENERATED_MARK" "$body" > "$out"
  log "wrote $out"
}

render_git_settings() {
  local out="$HOME/.gitconfig.settings" records signing key value
  records="$(settings_render_git)"
  signing="$(settings_get git.signing_key)"
  if ! _generated_or_absent "$out"; then
    warn "$out is not generated by bootstrap.sh - left untouched"
    return 0
```
